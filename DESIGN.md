## Color System

| Name | CSS Variable | Hex | Usage |
|---|---|---|---|
| Brand Blue | `--primary-color` | `#146CFF` | CTAs, highlights, borders, glows, icon accents |
| Brand Blue Hover | `--primary-hover` | `#3b82f6` | Interactive state for buttons and links |
| Background Dark | `--bg-dark` | `#090a0f` | Page background (Hero, Contacts sections) |
| Background Alt | `--bg-dark-alt` | `#11131c` | Section alternation (About section) |
| Navbar BG | `--bg-navbar` | `rgba(9,10,15,0.85)` | Frosted navbar surface (backdrop-filter) |
| Text Primary | `--text-light` | `#f8fafc` | Body copy, headings |
| Text Muted | `--text-muted` | `#94a3b8` | Subtitles, secondary labels, footer |

### Rules
- Brand Blue is the **only** accent color. No secondary accent colors.
- Never use gradients for brand color — use flat `#146CFF` fills only.
- Glow effects (box-shadow, drop-shadow, text-shadow) must use `rgba(20,108,255,...)` only.
- Dark backgrounds (`#090a0f`, `#11131c`) are intentional — do not lighten them.

## Typography

| Role | Font | Weight | Notes |
|---|---|---|---|
| Display / Headings | `Poppins` | 700, 600 | Used for `h1`, `h2`, `h3` |
| Body / UI | `Poppins` | 400, 300 | Paragraph text, nav links |
| Code / Accent | `Fira Code` | 400, 500 | Brand tagline `<Programador/>`, section prefixes `#`, footer, tech labels |

### Rules
- **Do not introduce Inter, Roboto, or any other font.** These two families are the entire type system.
- Monospace (`Fira Code`) signals the developer identity — use it for decorative/accent text only, not for body copy.
- `display-3` / `display-5` Bootstrap classes are used for the Hero heading — maintain this scale.

## Spacing & Layout

- Layout uses **Bootstrap 5 grid** (container, row, col-lg-*).
- Sections are `min-vh-100` to ensure full-bleed presence on scroll.
- Vertical padding on sections: `py-5` outer + `py-5` inner container = generous breathing room.
- No tight or cramped layouts. Sections must feel spacious.

## Motion & Animation

| Animation | Target | Style |
|---|---|---|
| `float` | Profile image | 6s ease-in-out infinite, 0→-15px→0 vertical |
| Matrix rain | Hero canvas (blue, `#146CFF`) | 50ms interval, opacity 0.25 — ambient, not dominant |
| Matrix rain | Contacts canvas (green, `#0f0`) | Triggered on WhatsApp hover, opacity 0.4 |
| GitHub rain | Icon shower | Triggered on GitHub hover, 150ms spawn interval |
| Hover lift | `.contact-item` | `translateY(-8px)`, cubic-bezier spring |
| Hover lift | Tech icons | `translateY(-5px) scale(1.1)` |
| Hover lift | `.btn-primary-custom` | `translateY(-3px)` |
| Scale pop | Language toggle | `scale(0.9)` → `scale(1)` on click |
| Fade | i18n text swap | 150ms fade-out, 300ms fade-in |

### Rules
- All transitions default to `0.3s ease` unless a spring/cubic-bezier is more appropriate (contacts card).
- Animations must be **ambient or triggered**, never autoplay on repeat in foreground content.
- No CSS `animation: spin`, `bounce`, or `shake` classes.

## Component Inventory

### Navbar
- Fixed-top, frosted glass (`backdrop-filter: blur(12px)`).
- Brand name: `<Programador/>` (PT) / `<Programmer/>` (EN) in `Fira Code`, brand blue.
- Nav links: white, weight 500, `translateY(-2px)` on hover.
- Language toggle: `btn-outline-primary-custom`, pill shape (`rounded-pill`), shows **target** language.

### Hero Section
- Full-viewport (`min-vh-100`), dark background with matrix canvas at z=0, opacity 0.25.
- Profile image floats on right column — `max-width: 450px`, `drop-shadow-custom`.
- CTA button: `btn-primary-custom`, pill shape, `shadow-primary`.
- No video, no carousel, no hero slider.

### About Section
- Alternating background (`bg-dark-alt`).
- Single centered column (`col-lg-8`), text-left on desktop, centered on mobile.
- Tech stack: icon grid, 70×70px tiles, `rgba(20,108,255,0.05)` fill, hover scales + glows.
- No progress bars, no skill percentages, no charts.

### Contacts Section
- Single card (`rounded-4`, `border-primary-custom`) centered in `col-lg-8`.
- Two contact items side-by-side (flex-row on md+): WhatsApp and GitHub.
- Hover effects on each item reveal background animations (matrix / icon rain).
- Card has a subtle glow blob (`glow-bg`) at top-right — pointer-events: none.

### Footer
- Minimal: copyright line + "Built with..." in `Fira Code`, muted color.
- `bg-dark-navbar` (reuses navbar style), thin top border.

## Accessibility Baseline

- All images must have descriptive `alt` text.
- Color contrast: white text on `#090a0f` and `#146CFF` must meet WCAG AA (≥4.5:1 for normal text).
- Canvas elements are decorative — they are presentational and do not convey information.
- Interactive elements (buttons, links) must have visible focus states.
- Language toggle must be keyboard-accessible.

---

## Forbidden Patterns (Design Enforcement)

| Pattern | Reason |
|---|---|
| `background: linear-gradient(135deg, #667eea, #764ba2)` | Classic AI slop purple gradient |
| `font-family: 'Inter'` | Wrong font for this project |
| Card-in-card layouts | Creates visual noise, breaks hierarchy |
| `border-radius: 50%` on square content containers | Use `rounded-4` (Bootstrap) = `border-radius: 1rem` |
| Neon green as a brand color | Green is only used for the WhatsApp hover matrix effect — not brand |
| Adding new sections without updating `PRODUCT.md` | Product scope must be preserved |
